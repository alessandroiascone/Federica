LEZIONI MATEMATICA — PWA PRONTA PER GITHUB PAGES

1) Crea una repository GitHub dedicata.
2) Carica NELLA ROOT della repo tutti i file e la cartella icons contenuti in questo ZIP.
3) GitHub: Settings > Pages > Build and deployment > Deploy from a branch.
4) Seleziona branch main e cartella /(root), quindi Save.
5) Apri l'indirizzo HTTPS generato da GitHub Pages sul telefono HONOR 600 usando Chrome.
6) Menu ⋮ > Installa app / Aggiungi a schermata Home.

NOTE IMPORTANTI
- La PWA e il funzionamento offline richiedono HTTPS: aprire index.html come file locale NON basta per installarla correttamente.
- I dati di alunni, lezioni e pagamenti restano nel browser/app del telefono tramite localStorage.
- Usare periodicamente Impostazioni > Esporta backup.
- Non cancellare i dati del sito/app senza aver prima esportato un backup.
- WhatsApp viene aperto dall'app con il messaggio già compilato.
